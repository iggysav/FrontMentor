### What I learned

Learned how to use clamp() for fluid font scaling in responsive layouts
```css
 h2 {
  margin: 0;
  color: #111111;
  font-size: clamp(1.25rem, 1.6667vw, 1.5rem);
  font-weight: 800;
}
```
