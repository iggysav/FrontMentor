### What I learned

This challenge helped me grow in several directions:

- **Semantic HTML**: I discovered the `<s>` element and learned when it's more appropriate than `<del>` for outdated content like old prices.

- **BEM naming**: I practiced structuring class names with blocks and modifiers (e.g., `box--info`, `product__title`) to keep my CSS organized and predictable.

- **SCSS**: I got my first real taste of Sass —  variables for colors and fonts made the styles much cleaner than plain CSS.  I also combined SCSS nesting with BEM naming to keep my styles structured and readable.

- **Responsive images**: I learned how the `<picture>` element lets the browser load a different image depending on screen size, saving bandwidth on mobile.

- **Flexbox alignment**: I finally understood the difference between `align-items` (individual items within a line) and `align-content` (the lines themselves inside a container).

### Continued development

In future projects, I want to go deeper in a few areas:

- **SCSS**: I've only used variables and nesting so far. Next I'd like to explore mixins, functions, and splitting styles into multiple partial files.

- **Responsive design**: I built this challenge desktop-first. I want to try a mobile-first approach.

- **CSS Grid**: I haven't used Grid yet. I'd like to understand when it's a better fit than Flexbox — especially for complex two-dimensional layouts.

- **Container queries**: I've heard about container queries but haven't tried them yet. They seem perfect for reusable components like this card — letting styles respond to the container's size instead of the viewport.
